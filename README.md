# Incident Data Analysis (Time-Based Trends)

## Overview

This project analyzes incident report data to identify patterns based on date and time. The goal is to understand when incidents are most likely to occur and how trends vary across different days.

---

## Tools Used

* Python
* pandas
* matplotlib / seaborn

---

## Key Insights

### Weekly Trends

* Fridays and Saturdays show the highest number of incidents
* Midweek days (like Tuesday) have significantly fewer cases

---

### Time-Based Patterns

* Incident frequency increases during peak hours
* Certain time ranges consistently show higher activity

---

### Pattern Recognition

* Clear clustering of incidents around specific days and times
* Helps identify high-risk periods for better planning and response

---

### Low Activity Periods

* Some days and hours remain consistently low
* Useful for resource allocation and scheduling

---

## Visualizations

* Heatmaps showing incidents by **day and time**
* Charts highlighting frequency spikes and trends

---
